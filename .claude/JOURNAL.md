2. **Task [Extended] - Advanced HTML viewer** (v0.1.4): Built HTML viewer with trust, refresh, marks, comments and notes panel; only file text takes a comment<br>
   **Result**: Design read from sibling `jupyterlab_advanced_markdown_viewer_extension` (README, 98 NOTES criteria, `src/`) and built-in `HTMLViewer` of JupyterLab 4.6.4 (sandbox `allow-same-origin allow-downloads`, trust adds `allow-scripts allow-popups`, so the lab reads the frame DOM in both states). File text vs page content: `src/source.ts` parses the file with parse5 7.3 and loads the frame with attribute `data-jp-ahv` numbering every start tag; a second parse gives each character's file offset, walking character references, CRLF, the dropped pre newline and ignored tags. `src/origin.ts` matches frame elements by number, parser-made elements by descendants, and counts a text node as file text only while it continues its element's file text, so script-added, script-rewritten and iframe content is refused (iframe rule added at the Star Colonel's word). Marks keep the Markdown viewer grammar (`src/marks.ts`, `--!>` escaped too), are painted through the CSS Custom Highlight API with an adopted stylesheet (`src/paint.ts`, page DOM untouched), and are written through new compare-and-write route `POST write` (`routes.py`) with the context revision moved in place. `src/follow.ts` polls the hash every 2 s; a change to markers alone repaints without reloading. Panel, handle, icons and swatches ported. Galata caught DEF-VIEW-1: Lumino box layout sends an update request on every refit, and rendering on it reloaded the page when the panel opened; the viewer now renders only on its own triggers. 66 criteria in `docs/acc-crit-advanced-html-viewer.md` closed through pm-tools; jest 61, pytest 8, Galata 56 green on 0.1.4, lint clean.
